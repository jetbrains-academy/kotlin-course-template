This task asks the student to implement a solution and runs tests from the [Tests.kt](./test/Tests.kt) file.
You must add _placeholders_ to the locations where the student needs to complete the code (see [task-info.yaml](./task-info.yaml)).

This task also demonstrates how to use the [Kotlin test framework](https://github.com/jetbrains-academy/kotlin-test-framework) 
to test functions or classes without relying on reference implementations in the test code itself.
